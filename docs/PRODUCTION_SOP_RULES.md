# 量產執行規則（Victor裁示版）
**適用：所有Superninja視窗**
**授權：Victor**
**日期：2026-06-06**

---

## 核心規則（不可違反）

### 規則一：必讀後才開工
每個新視窗開工前，依序必讀：
1. `cat docs/A_PLUS_PRODUCTION_MANUAL.md`（A+手冊 v5.1）
2. `cat docs/MUST_READ_BEFORE_START_v2.1.md`（必讀新法）
讀完說出開場白，才能開工。

### 規則二：HASH收據制度
```
SOP+QC自檢完成
→ Gate 1~6全部通過
→ 取得HASH收據
→ 才算1支完成

無HASH = 未完成 = 黑洞風險
```

### 規則三：每次只推送1支
每推送1支成品，讓Victor視覺品鑑，才繼續下一支。

### 規則四：首樣必檢
每一大批次的第1支完成後，**必須暫停**等Victor首樣視覺品鑑通過，才能繼續。

### 規則五：首樣通過後一無反顧
首樣品鑑通過後，從第2支起**一無反顧、奮勇直前**連續執行，不等每支確認。

### 規則六：每3支強制回讀
```
完成第3支 → 強制回讀A+手冊 → 繼續第4支
完成第6支 → 強制回讀A+手冊 → 繼續第7支
完成第9支 → 強制回讀A+手冊 → 繼續第10支
...依此類推
```
**鐵律：不可跳過。**

### 規則七：條件衝突發警訊
條件與實際工作衝突 → 立即發警訊給Victor → 暫停等裁示 → 不自作主張。

### 規則八：批次完成暫停
每個類別全數工具完成後暫停，等Victor視覺品鑑通過，才開始下一類別。
