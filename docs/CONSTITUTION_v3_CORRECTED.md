## 📌 關鍵修正

### 原始表述（不精準）
```
"BMI 是黃金母模板，所有工具是複製自 BMI"
```

**問題**：
- 容易導致 AI 誤解為「所有工具內容都與 BMI 相同」
- 忽視了每個工具的獨特計算邏輯和參數
- 可能導致量產時直接複製 BMI 內容而不進行替換

### 修正後的表述（精準）
```
"BMI 是黃金母模板，所有類似的工具的架構是複製自 BMI。
但每個工具的個別內容與其參數可能有極大差異。
各個工具必須參考其原始來源，使用其正確的內容和參數。"
```

## 📚 工具對比示例

### BMI 計算器
```
計算公式：weight / (height / 100)²
分類：6 級（Underweight, Normal, Overweight, Obesity I/II/III）
輸入：身高、體重
推薦商品：體重秤、健身追蹤器、補充品、健康書籍
```

### BMR 計算器
```
計算公式：Mifflin-St Jeor（10×weight + 6.25×height - 5×age ± 5/161）
分類：3 級（Low, Normal, High）
輸入：身高、體重、年齡、性別
推薦商品：智能體重秤、體脂計、蛋白質補充品、健身計畫書
```

### TDEE 計算器
```
計算公式：BMR × 活動係數（1.2/1.375/1.55/1.725/1.9）
分類：5 級（Sedentary, Light, Moderate, Active, Very Active）
輸入：BMR（或身高體重年齡性別）、活動等級
推薦商品：健身追蹤器、智能體重秤、運動手環、營養計畫書
```

### 熱量赤字計算器
```
計算公式：赤字 = TDEE - 每日攝取；體重變化 = 赤字 × 7 ÷ 7700
分類：5 級（Dangerous, Aggressive, Moderate, Conservative, Surplus）
輸入：TDEE、每日攝取、目標體重
推薦商品：食物秤、熱量計算 App、蛋白質補充品、減重計畫書
```

## 🚨 常見錯誤和防止方法

### 錯誤 1：複製後不進行替換
❌ **錯誤**：複製 BMI 後直接使用，沒有修改計算邏輯
✅ **正確**：複製後必須完全替換所有工具專屬內容

### 錯誤 2：只替換函數名稱
❌ **錯誤**：只改 `BmiCalculator` → `BmrCalculator`，保留 BMI 計算公式
✅ **正確**：替換函數名稱 + 計算邏輯 + 分類 + UI 標籤 + 商品

### 錯誤 3：複製錯誤的 locales
❌ **錯誤**：複製首頁的 locales 而不是 BmiCalculator 的 locales
✅ **正確**：驗證 locales 來源，確保複製正確的文件

### 錯誤 4：舊檔案衝突
❌ **錯誤**：新舊檔案並存，Vite 優先載入舊檔案
✅ **正確**：完全刪除舊檔案，確保只有新檔案存在

### 錯誤 5：忽視商業層
❌ **錯誤**：只複製計算邏輯，忽視商業層的實現
✅ **正確**：確保所有 5 層商業層都正確實現
