## 1. 工具製作核心原則

### 1.1 工具的本質定義

Formula Universe 的工具必須同時做到：

| 層次 | 說明 | 禁止 |
|---|---|---|
| 工具（Tool） | 提供精確計算或處理 | 只有輸入框和結果 |
| 知識（Knowledge） | 解釋公式、概念、背景 | 空白的「什麼是 X」|
| 公式（Formula） | 透明呈現計算邏輯 | 黑盒子輸出 |
| 解讀（Interpretation） | 告訴用戶結果代表什麼 | 「計算完成」就結束 |
| 決策建議（Decision） | 引導下一步行動 | 沒有後續指引 |
| 人類顧問（Human Advisory） | 針對不同情境給具體建議 | 空泛的「請諮詢專業人士」|

### 1.2 黃金法則

```
禁止草草交差。
禁止空白 FAQ。
禁止無解釋的結果。
禁止孤島工具（必須連結 Journey）。
禁止神化工具（必須說明限制）。
```

## 2. Gold Tool 必備結構（15層）

每個工具頁面必須包含以下所有層次：

### Layer 1：Hero
**目的：** 定義工具身份，吸引正確用戶  
**必須包含：**
- 工具名稱
- 一句精準用途描述
- 適用情境（2-4 個標籤）
- CTA 按鈕

**範例（BMI）：**
```
BMI 計算器
快速評估體重與健康風險

適合：減脂計畫 / 健身追蹤 / 健康檢查 / 體重管理
[立即計算]
```

**禁止：** 只有工具名，沒有情境說明

---

### Layer 2：Quick Guide
**目的：** 讓用戶 30 秒內知道怎麼用  
**必須包含：** 3-5 個步驟，每步驟一句話

**範例（BMI）：**
```
① 輸入你的身高（cm）
② 輸入你的體重（kg）
③ 點擊計算
④ 查看 BMI 數值與健康分類
⑤ 閱讀個人化建議
```

**禁止：** 沒有 Quick Guide，或只有「輸入→計算→結果」

---

### Layer 3：Examples
**目的：** 用真實數字讓用戶理解工具  
**必須包含：** 至少 3 個具體範例（含輸入值與輸出解讀）

**範例（BMI）：**
```
案例 A：170cm / 65kg → BMI 22.5 → 正常體重，維持現況
案例 B：165cm / 85kg → BMI 31.2 → 肥胖，需要介入
案例 C：175cm / 58kg → BMI 18.9 → 正常偏瘦，注意營養
```

**禁止：** 空白 Examples，或只有「例如：輸入你的數值」

---

### Layer 4：Calculator
**目的：** 提供精確計算  
**必須包含：**
- 清晰標示的輸入欄位（含單位）
- 輸入驗證（範圍檢查）
- 計算按鈕
- 公式來源標示

---

### Layer 5：Result
**目的：** 呈現計算結果  
**必須包含：**
- 數值結果（含單位）
- 分類/等級標示
- 視覺化（顏色、圖示）

**禁止：** 只顯示數字，沒有分類解釋

---

### Layer 6：Result Intelligence（結果解讀）
**目的：** 讓結果變成有意義的資訊  
**必須包含：** 針對當前結果的具體解讀

**範例（BMI 22.5）：**
```
✅ 正常體重區間（18.5–24.9）
你的體重處於健康範圍，心血管風險較低。
建議維持現有飲食與運動習慣，每 3 個月追蹤一次。
```

**禁止：**
```
BMI = 22.5
計算完成。
```

---

### Layer 7：Decision Layer（決策引導）
**目的：** 告訴用戶下一步做什麼  
**必須包含：** 基於結果的具體行動建議

**範例（BMI 過重）：**
```
你的下一步：
→ 計算每日熱量需求（TDEE）
→ 設定熱量赤字目標
→ 追蹤 BMR 變化
→ 每月量測體重趨勢
```

---

### Layer 8：Human Advisory（人類顧問建議）
**目的：** 針對不同結果區間提供專業建議  
**必須包含：** 至少覆蓋低/正常/高三個區間

**範例（BMI）：**

**偏瘦（< 18.5）**
```
可能原因：熱量攝取不足 / 肌肉量偏低 / 營養不均衡
建議：增加蛋白質攝取 / 加入阻力訓練 / 諮詢營養師
注意：體重過低可能影響免疫力與荷爾蒙
```

**正常（18.5–24.9）**
```
現況：維持良好
建議：保持規律運動 / 均衡飲食 / 每 3 個月追蹤
```

**過重（25–29.9）**
```
風險：心血管疾病風險上升 / 代謝症候群風險
建議：每日熱量赤字 300-500 kcal / 增加有氧運動 / 減少精製糖
```

**肥胖（≥ 30）**
```
風險：糖尿病 / 高血壓 / 睡眠呼吸中止
建議：諮詢醫師 / 結構性減重計畫 / 追蹤腰圍而非只看體重
```

**禁止：** 「請諮詢專業醫師」就結束

---

### Layer 9：Formula（公式透明）
**目的：** 讓用戶理解計算邏輯  
**必須包含：**
- 標準公式（含數學符號）
- 變數說明
- 單位說明
- 公式來源/標準

**範例（BMI）：**
```
BMI = 體重(kg) ÷ 身高(m)²

變數：
  體重：公斤（kg）
  身高：公尺（m）= 輸入的 cm ÷ 100

來源：世界衛生組織 (WHO) 標準
```

---

### Layer 10：Knowledge（知識層）
**目的：** 建立概念理解  
**必須包含：**
- 概念定義（2-3 句精準說明）
- 歷史/背景（選填，1-2 句）
- 適用範圍
- 不適用範圍（限制）

**範例（BMI 限制）：**
```
BMI 的限制：
❌ 不考慮肌肉量（健身者 BMI 可能偏高但體脂正常）
❌ 不反映脂肪分佈（腹部脂肪風險更高）
❌ 不適用孕婦、老年人、兒童的標準判斷
✅ 適合：快速初步篩查體重健康風險
```

---

### Layer 11：Trust（信任聲明）
**目的：** 建立用戶信任，說明工具邊界  
**必須包含：**
- 數據來源
- 適用範圍聲明
- 免責聲明（健康/財務工具必填）

**範例：**
```
本工具基於 WHO 及亞太區 BMI 分類標準。
計算結果僅供參考，不構成醫療診斷。
如有健康疑慮，請諮詢合格醫療人員。
```

---

### Layer 12：FAQ
**目的：** 回答用戶真實疑問  
**必須包含：** 至少 5 個有深度的 FAQ

**禁止的 FAQ：**
```
Q: 什麼是 BMI？
A: BMI 是身體質量指數。
```

**正確的 FAQ：**
```
Q: BMI 高但我感覺很健康，需要擔心嗎？
A: BMI 是初步篩查工具，不是診斷工具。如果你的肌肉量高（如健身者），
   BMI 可能偏高但實際體脂正常。建議搭配體脂率測量來綜合評估。

Q: 亞洲人的 BMI 標準和西方人一樣嗎？
A: 不一樣。亞太地區通常以 23 作為過重臨界值（WHO 全球標準是 25），
   因為亞洲人在較低 BMI 時就可能出現代謝風險。

Q: 減重多少才能讓 BMI 回到正常？
A: 以 170cm/80kg（BMI 27.7）為例，需減約 4.5kg 才能達到 BMI 25。
   建議每月減 0.5-1kg 為健康速度。
```

---

### Layer 13：Related Tools（關聯工具）
**目的：** 建立工具之間的語義圖譜  
**必須包含：** 3-6 個相關工具，並說明關聯關係

**範例（BMI）：**
```
→ BMR 基礎代謝率：了解每日最低熱量需求
→ TDEE 每日總消耗：計算維持體重所需熱量
→ 熱量赤字計算：設定減重目標
→ 體脂率估算：更精準的體組成評估
→ 蛋白質需求計算：確保肌肉維持
```

---

### Layer 14：Related Articles（關聯文章）
**目的：** 連結工具與知識庫文章  
**必須包含：** 2-4 篇相關文章（可為候選，尚未發布也要列出）

**範例（BMI）：**
```
📄 BMI 完整指南：從計算到健康行動
📄 減脂完整流程：BMI → TDEE → 熱量赤字
📄 為什麼健身者不應該只看 BMI
📄 亞洲人 BMI 標準：與全球標準的差異
```

## 3. 各類別工具示範

### 3.1 財經工具（CAGR）

**Formula：**
```
CAGR = (終值 / 初值)^(1/年數) - 1

例：100 萬 → 200 萬，10 年
CAGR = (200/100)^(1/10) - 1 = 7.18%
```

**Result Intelligence：**
```
CAGR 7.18% 的意義：
✅ 優於台灣定存（約 1.5%）
✅ 接近全球股市長期平均（7-10%）
⚠️ 需要考慮通膨侵蝕（實質報酬率約 4-5%）
```

**Human Advisory：**
```
低於 3%：建議檢視投資組合，考慮增加股票比重
3%-7%：穩健成長，適合保守型投資人
7%-12%：良好表現，接近全球市場平均
超過 15%：需確認風險是否可承受
```

**限制說明：**
```
❌ CAGR 不反映中間波動（可能某年大跌）
❌ 過去 CAGR 不代表未來績效
✅ 適合：比較不同投資的長期效率
```

---

### 3.2 開發工具（JSON Formatter）

**Quick Guide：**
```
① 貼上你的 JSON 字串
② 點擊「格式化」
③ 查看縮排後的結構
④ 如有錯誤，查看錯誤位置提示
⑤ 複製格式化結果
```

**Knowledge：**
```
JSON（JavaScript Object Notation）是輕量級資料交換格式。
格式化的目的：提高人類可讀性，不改變資料內容。

常見錯誤：
- 多餘的逗號（trailing comma）
- 字串未用雙引號
- 巢狀括號不對稱
```

**Result Intelligence：**
```
✅ 有效 JSON：結構正確，可安全用於 API 傳輸
❌ 無效 JSON：第 3 行第 15 字元：unexpected token
```

---

### 3.3 健康工具（BMR）

**Formula：**
```
Mifflin-St Jeor 公式（目前最準確）：

男性：BMR = 10×體重(kg) + 6.25×身高(cm) - 5×年齡 + 5
女性：BMR = 10×體重(kg) + 6.25×身高(cm) - 5×年齡 - 161

例（男性，70kg、175cm、30歲）：
BMR = 700 + 1093.75 - 150 + 5 = 1648.75 kcal/天
```

**Human Advisory：**
```
BMR < 1200 kcal（女性）/ < 1400 kcal（男性）：
⚠️ 代謝偏低，可能原因：肌肉量不足、長期節食
建議：增加阻力訓練，避免低於 BMR 的飲食計畫

BMR 正常範圍：
✅ 這是你靜止時的最低熱量需求
絕對不要攝取低於 BMR 的熱量（器官損傷風險）
```

## 6. 工具知識範例庫（TOOL_KNOWLEDGE_GUIDE）

以下為各類別精選工具的知識要素，供 AI 填充工具頁面時參考：

### 財經類（Finance）

| 工具 | 公式核心 | 關鍵限制 | 必備 Related |
|---|---|---|---|
| CAGR | (終值/初值)^(1/n)-1 | 不反映波動 | 複利計算、退休計算 |
| 複利計算 | P×(1+r)^n | 假設利率固定 | CAGR、退休計算 |
| 退休計算 | 4% 法則、FV 公式 | 不考慮通膨變動 | CAGR、複利、FIRE |
| FIRE 計算 | 年支出×25 | 假設 4% 提領率 | 退休計算、CAGR |

### 健康類（Health）

| 工具 | 公式核心 | 關鍵限制 | 必備 Related |
|---|---|---|---|
| BMI | kg/m² | 不考慮肌肉量 | BMR、TDEE、體脂率 |
| BMR | Mifflin-St Jeor | 僅適合一般人 | TDEE、熱量赤字 |
| TDEE | BMR × 活動係數 | 係數為估算值 | BMR、熱量赤字 |
| 熱量赤字 | TDEE - 目標攝取 | 不能低於 BMR | BMR、TDEE |

### 開發類（Dev）

| 工具 | 功能核心 | 關鍵限制 | 必備 Related |
|---|---|---|---|
| JSON Formatter | 縮排 + 驗證 | 只驗證語法 | API Tester、Regex |
| Regex Tester | 正則表達式測試 | 各語言略有差異 | JSON、API |
| API Tester | HTTP 請求測試 | 不儲存憑證 | JSON、Regex |
