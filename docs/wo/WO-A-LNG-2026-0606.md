## 核心功能規格

### 使用者體驗
1. 輸入任意一串英文字母（如 `silten`）
2. 點擊「Find Words」
3. 工具排列組合，透過 Datamuse API 查詢
4. 顯示所有有意義的英文單字（如 listen / silent / enlist / tinsel / inlets）
5. 每個結果顯示：單字 + 分數 + 詞性（如有）

### Datamuse API 規格

```javascript
// API endpoint（免費，無需API key）
const BASE = "https://api.datamuse.com/words"

// 查詢所有包含這些字母的anagram
const letters = input.split('').sort().join('')
const url = `${BASE}?sp=${input}&md=p&max=20`

// 實際anagram查詢：用 rel_anag 參數
// 例：查詢 "listen" 的所有anagram
const url = `${BASE}?rel_anag=listen&md=p`

// 但若輸入是亂序字母，需先找出所有排列組合再查詢
// 建議方法：
// 1. 先用 ?sp=* 配合字母過濾（Datamuse支援wildcard）
// 2. 或用 ?letters=silten（查詢包含這些字母的單字）
const url = `https://api.datamuse.com/words?sp=${sortedLetters}&md=p&max=30`
```

### 正確 API 呼叫方式

```javascript
// 輸入字母排序後作為pattern
const sorted = userInput.toLowerCase().split('').sort().join('')

// Datamuse anagram查詢（最直接）
const response = await fetch(
  `https://api.datamuse.com/words?rel_anag=${userInput}&md=p&max=30`
)
const words = await response.json()
// 回傳格式：[{ word: "listen", score: 2906, tags: ["v"] }, ...]

// 若rel_anag結果少，補充sp查詢
const response2 = await fetch(
  `https://api.datamuse.com/words?sp=${userInput}&md=p&max=20`
)
```

### 結果顯示規格
```
每個單字卡片顯示：
- 單字本體（大字，font-black）
- 分數（score，代表使用頻率）
- 詞性標籤（n=名詞 v=動詞 adj=形容詞）
- 字母數
```
