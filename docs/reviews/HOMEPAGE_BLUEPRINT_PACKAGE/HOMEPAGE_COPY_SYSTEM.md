# HOMEPAGE_COPY_SYSTEM.md

## Purpose

This document defines the copy system for the Formula Universe homepage. The homepage must communicate Formula Universe as an AI Native Knowledge Operating System, not just a list of calculators. Copy must be clear, trustworthy, bilingual-ready, and safe for finance, health, AI, and decision-support contexts.

This document is a copy specification only. It does not authorize `.tsx` edits, route changes, registry changes, Canonical ID creation, commits, or deployment.

## Copy Principles

1. Use precise, modest language.
2. Avoid guaranteed outcomes.
3. Treat tools as part of knowledge journeys.
4. Explain formulas, limitations, and next steps.
5. Do not claim AI functionality before it exists.
6. Do not imply medical, financial, or legal advice.
7. Keep Traditional Chinese and English meaning aligned.

## Forbidden Phrases

The homepage must avoid unsupported or unsafe language such as:

| Forbidden phrase | Reason |
|---|---|
| Guaranteed retirement success | Unsupported financial claim |
| Accurate medical diagnosis | Unsafe health claim |
| AI will make the decision for you | Misrepresents decision support |
| Perfect investment plan | Unsupported financial claim |
| Scientifically proven for everyone | Overgeneralized claim |
| 100% correct answer | Formula tools are context-dependent |
| Replace your doctor | Unsafe medical claim |
| Replace your financial advisor | Unsafe financial claim |
| Fully automated knowledge graph | Only allowed after real implementation |
| Live AI personalization | Only allowed after real implementation |

Preferred wording:

```txt
Estimate
Explore
Understand
Compare
Learn the formula
See limitations
Find the next step
Support better decisions
```
