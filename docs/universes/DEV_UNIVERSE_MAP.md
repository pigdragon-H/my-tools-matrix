## 六、命名規則

- Galaxy Key：3字母 UPPERCASE，永久穩定
- 禁止：developer-tools、dev-utils、format-tools
- 必須：FMT、CNV、VAL

---

## 七、語意邊界（重要）

| 類型 | Galaxy | 定義 |
|------|--------|------|
| CNV | Conversion | data transformation |
| ENC | Encoding | encoding/decoding |
| FMT | Formatting | beautify/normalize |
| VAL | Validation | validation/checking |

禁止混淆這四個 Galaxy。
