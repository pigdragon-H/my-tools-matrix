### 特色工具：Vocabulary DNA Engine

這是Formula Universe的差異化武器，別家少做：

```
輸入：innovation

輸出：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
詞根：in（進入）+ nov（新）+ ation（名詞）
衍生字：innovate / innovative / innovator
同義詞：creativity / invention / breakthrough
CEFR：C1（進階）
詞頻：Top 5000
例句：Innovation drives economic growth.
AI測驗：[開始測驗這個字]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
