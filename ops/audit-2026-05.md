## 決策

> **不在這次 cleanup 對 BMR 做大改**。理由：
> 1. BMR 已 build / runtime 正常，內容文案符合 YMYL（CDC/Mifflin-St Jeor 引用）
> 2. 若把 BMR 升級到 100%，要動到 5 個區段，會把 review 焦點從「金樣鎖定」拉走
> 3. **BMI 已是 100% 黃金樣板**，量產可以單以 BMI 為唯一基準

> 量產時的對策：
> - SOP / skeleton / QC 全部以 BMI 為事實上的金樣
> - 新工具走 §A 17/17 + §E 6/6 才算過關
> - BMR 標記為 **legacy reference**（含可學/不可學註解，已寫在 `ops/examples/README.md`）
> - 等量產第 3 / 4 支工具穩定後，再回頭升級 BMR

## 量產時的硬規則（從本次審計提煉）

1. **不准建 `locales/` 子目錄**（黃金標準是 inline `ui = { zh, en }`）
2. **L6 三格必須是 Risk Summary / Recommended Action / Next Tool**（即使是低風險工具也要寫，可改成「使用要點/建議行動/下一步工具」這類溫和變體，但**結構不能少**）
3. **L9 / L10 必須是兩個獨立 grid 區段**（不能合併成一個）
4. **L12 / L13 必須並排 `lg:grid-cols-[1fr_0.9fr]`**（不能縱向各佔一行）
5. **AdSlot 必須帶 `position` prop，不能傳 `className`**
