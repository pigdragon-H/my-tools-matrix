# 預測性人才流失模型：在員工提離職前先看見徵兆的原理與落地

大多數公司面對人才流失的姿態都是被動的。等到一位優秀員工把辭呈放到桌上。主管才驚覺「怎麼會走」。然後手忙腳亂地開始挽留、交接、補人。但這時往往為時已晚。因為一個人決定離開。通常不是辭呈那天才發生的。而是在那之前好幾個月。各種不滿、倦怠、被忽略的訊號早已悄悄累積。預測性人才流失模型想做的。就是把這個時間軸往前拉。讓組織在員工真正遞出辭呈前。先從一連串訊號中辨識出「誰的流失風險正在升高」。從而有機會在還來得及的時候主動介入。這篇文章想把這件事講清楚。包括這個模型到底如何運作、需要哪些資料、落地時該照哪些步驟走、又有哪些倫理界線絕對不能越過。讓你的組織從「離職後才善後」的被動。轉向「徵兆出現就行動」的主動。把留才這件事。從碰運氣變成有方法。

## 一、為什麼流失總是太晚才被發現

要理解預測性模型的價值。先得弄懂為什麼人才流失總是太晚才被察覺。第一個原因是訊號太分散。一個員工的流失徵兆。可能散落在好幾個地方。績效的微妙下滑、參與度的降低、與團隊互動的減少、加班意願的轉變。單看任何一項都不足以拉警報。可是它們加在一起卻很有意義。問題是平常沒有人會把這些零散訊號拼在一起看。第二個原因是主管的盲區。一線主管每天忙於業務。很難對每位部屬的狀態都保持敏感。尤其團隊一大。更容易漏掉那些不擅長表達不滿、只是默默準備離開的人。第三個原因是人的慣性樂觀。我們傾向相信「他應該還好」。直到事實打臉。這三個原因疊在一起。造成的結果就是流失永遠是後知後覺。預測性人才流失模型的核心價值。正是針對這三個盲點。它能把分散的訊號自動匯集、能不帶情緒地持續監看每一個人、能在風險升高時主動提醒。從而補上人類主管做不到的那一塊。理解了流失為何總是太晚被發現。你才會明白這個模型補的是組織哪一個結構性的洞。下一步要談的。是它靠哪些訊號來做判斷。

## 二、它需要哪些訊號才能判斷風險

預測性人才流失模型要運作。需要一組能反映員工狀態的訊號。這些訊號大致分成幾類。第一類是工作參與相關的訊號。例如產出的變化、專案投入的程度、主動承擔的意願有沒有改變。這類訊號回答的是「這個人對工作的投入度是不是在下降」。第二類是互動與連結相關的訊號。例如與團隊協作的頻率、在內部討論中的活躍度、與主管溝通的密度。這類回答的是「這個人跟組織的連結是不是在變弱」。第三類是組織經歷相關的訊號。例如距離上次晉升或調薪多久了、最近有沒有經歷組織變動、所在團隊的整體流動率高不高。這類回答的是「這個人所處的環境是不是容易讓人想走」。把這幾類訊號組合起來。模型才能估出一個相對的流失風險。這裡必須鄭重提醒一件事。這些訊號的使用有非常明確的倫理界線。模型該看的是與工作直接相關的、員工知情的資料。絕對不能去窺探私人通訊、監控與工作無關的個人生活。一旦越過這條線。模型不但失去正當性。更會徹底摧毀員工的信任。讓組織氣氛雪上加霜。所以負責任的做法是只用必要且正當的訊號。並對員工保持透明。把訊號的邊界守住。這個模型才站得住腳。接下來才談得上它怎麼把訊號變成判斷。

## 三、它如何把訊號變成一個風險判斷

有了訊號。模型怎麼把它們變成一個可以行動的風險判斷。這個過程可以用一張流程圖來理解。

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│ 1.匯集工作訊號 │ ▶ │ 2.估算風險高低 │ ▶ │ 3.提醒該關注的 │ ▶ │ 4.主管一對一 │
│  參與互動經歷  │   │  排出關注名單  │   │  人並附線索    │   │  真誠對話介入 │
└──────────────┘   └──────────────┘   └──────────────┘   └──────────────┘
       ▲                                                          │
       └──────  對話結果回流 → 校準判斷 → 下次更貼近真實  ────────┘
```

流程的起點是匯集工作訊號。把參與、互動、經歷等與工作相關的訊號集中起來。第二步是估算風險高低。模型依這些訊號排出一份「值得特別關注」的名單。要強調的是它給的是相對的風險高低。而不是斷言誰一定會走。第三步是提醒該關注的人並附上線索。讓模型不只丟出一個名字。還說明是哪些訊號讓風險升高。例如「近三個月產出與互動同步下降」。好讓主管心裡有底。第四步是主管的真誠對話。這一步至關重要。模型的角色到此為止。真正要做的是讓主管去跟這位同仁好好聊一聊。理解他遇到了什麼、需要什麼。最後那條回饋迴路同樣關鍵。對話的結果會回流。校準模型的判斷。讓它下次更貼近真實。這套流程裡最該記住的一點是。模型的終點永遠是「促成一場人對人的對話」。而不是替主管下「這個人要走」的結論。理解了這套運作。你就能看出它跟冷冰冰的監控系統有著本質的不同。

## 四、用一段 Prompt 幫主管準備留才對話

模型給出關注名單後。許多主管卡在「我該怎麼開口談」。這時可以借 AI 幫忙準備對話。下面是一段可直接套用的 Prompt 範本。

```
【角色】你是一位擅長員工關懷的人資夥伴。
【背景】我是一位團隊主管，有一位表現不錯的部屬，
最近的工作投入與團隊互動似乎在下降，我想找他做一次關心的對話。
我並不確定原因，也不想讓他覺得被監控或被質疑。
【任務】請幫我準備這場對話：
1. 列出幾個能自然開啟話題、不帶壓力的開場方式。
2. 提供幾個能引導他願意說出真實想法的問題。
3. 提醒我在對話中該避免的說法與態度。
【限制】語氣要真誠關心，不要像審問；不要替我猜測或斷定他想離職的原因。
```

這段 Prompt 的價值。在於它把「準備一場有溫度的留才對話」這件主管常感棘手的事。拆成開場、提問、提醒三塊。讓 AI 先給出一份對話腳本的草稿。再由主管依與這位同仁的實際關係調整。實際使用時建議多輪互動。先讓它給開場與提問。你檢查語氣會不會太刻意。再請它針對可能聊到的方向多備幾個追問。要特別留意限制那段。要求 AI 不要替你猜測或斷定對方想離職的原因。這呼應了前面說的。模型與工具都只是輔助。真正理解一個人為什麼想走的。只能是那場真誠的對話本身。把這段產出接回第三節流程圖裡「主管一對一對話」那一步。模型的風險提醒就能順利轉化成一次有準備、有溫度的介入。

## 五、導入預測性人才流失模型的步驟

理解了原理。接下來是實際導入。一條穩健的導入路徑可以照下面這幾步走。第一步是先把目的對齊清楚。要在組織內明確宣示。這個模型的目的是「幫助組織更早關心員工」。而不是「監控員工、找人開刀」。目的講不清。再好的模型都會引發恐懼與抵抗。第二步是劃定資料的倫理邊界。明確界定哪些與工作相關的訊號可以用、哪些私人領域絕對不碰。並讓員工知情。第三步是先小範圍試行。挑一個願意配合的部門。讓模型跑出關注名單。但只把名單給該部門主管當參考。觀察介入對話的效果。第四步是建立配套的關懷機制。模型只負責提醒。組織必須同時準備好主管的對話訓練與實際能提供的支持。否則提醒了卻什麼都做不了。也是枉然。第五步是依結果持續校準。把對話得到的真實情況回饋給模型。並檢討整套機制有沒有真的降低流失。這條路徑的精神。是把模型放在一個「以關懷為目的、以人為終點」的框架裡。技術只是輔助。真正讓人才留下的。是組織願不願意因為這些提醒而真誠地關心人、解決問題。少了這個框架。模型再準也只會變成讓員工人人自危的監視器。

## 六、衡量成效與估算投入成本

預測性人才流失模型值不值得做。要把成效與成本攤開來看。成效面最該看的不是模型預測得多準。而是「組織有沒有因此更早地、更有效地留住該留的人」。常用的衡量方式是比較導入前後的關鍵人才留任率。以及流失的提前預警時間有沒有拉長。要小心一個陷阱。不要只追求預測準確率。一個能準確預測誰會走、卻沒能促成任何有效介入的模型。對組織毫無價值。成本面則包含三塊。一是資料整合與模型建置的一次性成本。二是配套的主管訓練與關懷機制成本。這塊常被低估卻最關鍵。三是持續的維運與校準成本。這裡用一張表把成本與對應的成效衡量對照呈現。所有數字皆為設想情境的示意。請以自身狀況估算。

| 投入項目 | 性質 | 對應成效衡量 |
| --- | --- | --- |
| 資料整合與模型建置 | 一次性為主 | 預警的提前時間 |
| 主管訓練與關懷機制 | 持續性 | 介入對話的有效率 |
| 維運與校準 | 持續性 | 關鍵人才留任率 |

這張表想傳達的。是這個模型的投入絕不能只算技術那一塊。真正讓它產生價值的。是右邊那兩列裡的關懷機制與留任成效。設想一家中型企業導入後。發現光有模型卻沒訓練主管怎麼對話。提醒等於白給。健康的做法是把關懷機制的成本一併算進去。並用留任率而非預測準確率來衡量成敗。把成效估保守、把配套成本估足。如果這樣算下來。模型帶來的留才效益仍能涵蓋投入。它就值得做。把帳這樣老實算清。預測性人才流失模型才會是一套真正服務於人的工具。而不是一個披著科技外衣、實則破壞信任的監控裝置。

## 七、❓ 讀完後。先問自己這幾個問題

在動手導入這個模型之前。先誠實回答下面幾題。

**你導入這個模型的真正目的，是想更早地關心與留住員工，還是只是想要一套能監控誰想走的系統？**

- 你劃定的資料邊界。守得住只看工作相關訊號、不碰私人領域這條倫理線嗎？
- 模型提醒之後。你的組織真的準備好讓主管去做有溫度的對話、並提供實質支持了嗎？
- 你打算用什麼衡量成敗。是看預測有多準。還是看該留的人有沒有真的被留下來？

## 結語與下一步

預測性人才流失模型的真正價值。不在於精準預言誰會離職。而在於把組織關心員工的時間軸往前拉。讓徵兆在還來得及的時候被看見。它需要一組與工作相關、員工知情的訊號。需要一條以真誠對話為終點的流程。更需要被放進一個以關懷為目的的框架裡。與其追問「我們能不能預測誰會走」。不如問「我這個模型的目的正不正、倫理邊界守不守得住、配套的關懷做不做得到」。下一步建議你先在組織內把目的對齊清楚。劃定好資料的倫理界線。挑一個願意配合的部門小範圍試行。並同步準備好主管的對話訓練與實質支持。讓這個模型在你的組織裡。從一個提醒工具。慢慢長成一套真正幫助人才願意留下來的留才能力。
