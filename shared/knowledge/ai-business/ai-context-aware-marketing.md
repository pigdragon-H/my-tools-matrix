# AI 情境感知行銷：依使用者情境即時調整訊息的原理與落地

許多品牌都聲稱自己在做「個人化行銷」。實際拆開來看卻常常只是把客戶名字塞進信件開頭。這種做法的問題在於它只認得「你是誰」。卻完全不理會「你現在處於什麼狀況」。一個剛把商品加入購物車卻沒結帳的人。跟一個已經買過三次的老顧客。需要的訊息天差地別。可是傳統行銷往往用同一套素材打給所有人。情境感知行銷想解決的正是這個落差。它讓訊息不只看「使用者是誰」。更看「使用者此刻的時間、地點、裝置、行為與意圖」。再依這個當下的情境即時挑選最合適的內容。這篇文章想把這件事講清楚。包括它到底如何運作、需要哪些資料當燃料、落地時該照哪些步驟走、又該怎麼衡量它帶來的成效。讓你手上那個模糊的「我們也想做個人化」的期待。變成一套真正能動手執行的方法。

## 一、情境感知行銷到底在感知什麼

要理解情境感知行銷。先得弄懂它說的「情境」具體指哪些東西。情境不是單一資料。而是好幾種訊號疊在一起構成的當下狀態。第一種是時間情境。同一個人在週一早上通勤時與週五深夜放鬆時。對訊息的接受度與興趣截然不同。第二種是空間情境。使用者人在門市附近、在家裡、還是在出差途中。會大幅影響哪一種促購方式有效。第三種是裝置情境。用手機快速瀏覽與用電腦仔細比較。適合的內容長度與形式並不一樣。第四種是行為情境。也就是使用者最近做了什麼。看了哪些頁面、把什麼放進購物車又拿出來、上次互動是多久以前。第五種是生命週期情境。這個人是剛認識品牌的新客、猶豫中的潛在客、還是已經回購多次的忠實客。把這五種訊號組合起來。系統就能拼出一張「此人此刻」的狀態圖。而情境感知行銷的核心。就是依這張狀態圖。從一堆候選訊息裡挑出最貼合當下的那一則。理解了情境由這些訊號構成。你才會明白為什麼它比「把名字填進去」的假個人化深刻得多。下一步要談的。就是這些訊號從哪裡來。

## 二、它需要哪些資料當燃料

情境感知行銷再聰明。沒有資料當燃料也跑不起來。它需要的資料大致分成三層。第一層是身分與屬性資料。例如使用者的基本輪廓、過去的購買紀錄、所屬的客群分類。這層資料相對穩定。回答的是「這個人大致是誰」。第二層是即時行為資料。例如此刻正在瀏覽的頁面、停留多久、點了什麼、購物車裡有什麼。這層資料變動快。回答的是「這個人現在在做什麼」。第三層是環境訊號。例如當下的時間、使用的裝置、進入的來源管道。這層回答的是「這次互動發生在什麼脈絡下」。把這三層資料接起來。系統才有辦法判斷情境。這裡有一個務實又重要的提醒。資料的取得與使用必須建立在使用者知情且同意的基礎上。情境感知行銷的力量越強。越要審慎處理隱私。否則一旦讓使用者感覺被過度窺探。再精準的訊息也只會引發反感。所以負責任的做法是只蒐集真正需要的資料、清楚告知用途、並給使用者選擇的權利。把資料這層打通且做得正當。情境感知行銷才有穩固的地基。接下來才談得上它如何把資料轉成決策。

## 三、它如何把情境轉成一則訊息

有了情境訊號與資料。系統怎麼把它們變成一則該發出去的訊息。這個過程可以用一張流程圖來理解。

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│ 1.蒐集情境訊號 │ ▶ │ 2.判讀當下情境 │ ▶ │ 3.挑選候選訊息 │ ▶ │ 4.即時送出   │
│  時間行為裝置  │   │  拼出狀態圖    │   │  比對最貼合的  │   │  並記錄回饋   │
└──────────────┘   └──────────────┘   └──────────────┘   └──────────────┘
       ▲                                                          │
       └──────  回饋資料回流 → 更新判讀規則 → 下次更準  ──────────┘
```

整個流程的起點是蒐集情境訊號。系統把時間、行為、裝置等訊號匯集起來。第二步是判讀當下情境。把這些訊號拼成一張「此人此刻」的狀態圖。例如判斷出「這是一位週五晚上用手機瀏覽、購物車有商品卻遲遲未結帳的潛在客」。第三步是挑選候選訊息。系統從事先準備好的一組訊息裡。比對哪一則最貼合這個狀態。可能是一則限時的免運提醒。第四步是即時送出並記錄回饋。看使用者有沒有點開、有沒有完成購買。最關鍵的是最後那條回饋迴路。每一次互動的結果都會回流。讓系統下次判讀得更準、挑選得更好。這條迴路是情境感知行銷能越用越聰明的原因。它不是設定好就僵在那裡的規則。而是會隨著資料累積持續校準的活系統。理解了這套運作。你就能看出它跟一次性大量群發的根本差別。

## 四、用一段 Prompt 讓 AI 幫你設計情境訊息

落地的第一個實務難題。常常是「同一個商品要為不同情境準備不同訊息」這件事工作量太大。這時可以借 AI 之力。下面是一段可直接套用的 Prompt 範本。

```
【角色】你是一位專精情境行銷的文案策略顧問。
【背景】我們的商品是（簡述商品與目標客群）。
我想為同一個商品，依不同使用者情境準備不同的行銷訊息。
【任務】請依下列三種情境，各寫一則訊息草稿：
1. 購物車有商品卻未結帳的潛在客（手機、晚間瀏覽）。
2. 半年未回購的老客戶（電腦、上班時段）。
3. 第一次造訪、尚未註冊的新訪客。
每則請說明：想觸發什麼行動、用什麼語氣、為何適合該情境。
【限制】語氣要貼近真人，不要過度推銷；不要假設任何我沒提供的客戶資料。
```

這段 Prompt 的價值。在於它把「為多種情境各備一套訊息」這件繁瑣的事。拆成清楚的任務交給 AI 先出草稿。再由懂品牌的人潤飾定案。實際使用時建議多輪互動。先讓它依三種情境出草稿。你檢查語氣與訴求合不合品牌調性。再請它針對效果最好的那種情境延伸更多變體。要特別留意限制那一段。要求 AI 不要假設你沒提供的客戶資料。這呼應了前面說的隱私原則。AI 給的是內容素材的起點。最終哪一則對哪種情境發送。仍要由人依策略拍板。把這段產出接回第三節流程圖裡「挑選候選訊息」那一步。你就有了一個源源不絕的訊息素材庫。

## 五、導入情境感知行銷的步驟

理解了原理。接下來是實際導入。一個穩健的導入路徑可以照下面這幾步走。第一步是先選定一個高價值的情境場景當試點。例如「購物車未結帳」這個轉換率影響最大的場景。不要一開始就想覆蓋所有情境。第二步是盤點你手上能合法取得的資料。確認這個情境需要的訊號你拿得到。例如購物車狀態、瀏覽裝置、上次互動時間。第三步是為這個情境準備好一組候選訊息。並訂出清楚的觸發規則。什麼狀態該發哪一則。第四步是小範圍試跑。只對一部分使用者開啟。並設好對照組。觀察有沒有真的提升成效。第五步是依數據修正。把試跑學到的調整回規則裡。再逐步擴大到其他情境場景。這條路徑的精神。是從單一最有價值的場景開始。用對照組驗證效果。確認有效再放大。而不是一口氣想做到無所不包。許多情境行銷專案失敗。正是因為一開始貪大求全。鋪了太多情境卻每個都做得淺。試點先把一個場景做深做透。累積出成功經驗與團隊信心。再複製到下一個場景。這樣的節奏遠比全面開花來得穩健可靠。

## 六、衡量成效與估算投入成本

情境感知行銷值不值得做。要把成效與成本都攤開來看。成效面最該看的不是發了多少訊息。而是「對的訊息有沒有帶來更好的結果」。常用的衡量方式是設對照組。一組收到依情境調整的訊息。一組收到原本的統一訊息。比較兩組在轉換率、回購率、互動率上的差異。這樣才知道情境調整本身帶來多少增益。而不是把整體成長都歸功於它。成本面則包含三塊。一是資料的串接與整理成本。要把三層資料打通並不輕鬆。二是訊息素材的製作成本。多情境意味著要備更多內容。三是系統與維運成本。包含規則的設定、監控與持續校調。這裡用一張表把成本與對應的衡量重點對照呈現。所有數字都是設想情境的示意。請以自身實際狀況估算。

| 投入項目 | 性質 | 對應衡量重點 |
| --- | --- | --- |
| 資料串接與整理 | 一次性為主 | 情境判讀的準確度 |
| 訊息素材製作 | 持續性 | 各情境的互動率 |
| 系統設定與維運 | 持續性 | 對照組的轉換增益 |

這張表想傳達的是。情境感知行銷的投入要對應到能驗證的成效。而不是憑感覺說「感覺有變好」。健康的做法是把成效估保守、把成本估寬鬆。例如設想一家中型電商先從單一場景試點。用對照組量出轉換增益。再換算成可接受的回本期。如果連保守估算都划算。這個投入就值得做。如果非得把增益估到很樂觀才划算。那也許該先把試點場景做得更扎實。把帳算清楚。情境感知行銷才是一筆心裡有底的投資。而不是追逐個人化潮流的盲目跟風。

## 七、❓ 讀完後。先問自己這幾個問題

在動手做情境感知行銷之前。先停下來想一想。會幫你少走很多冤枉路。

**如果只能先做一個情境場景。你會挑哪一個——它真的是價值最高、資料拿得到、又能用對照組驗證的那一個嗎？**

- 你想感知的情境訊號。你目前真的能合法且正當地取得嗎？
- 你準備好為這個情境備齊一組候選訊息了嗎。還是只想沿用一套打天下？
- 你打算怎麼用對照組去驗證成效。確認增益是來自情境調整。而不是其他因素？

## 結語與下一步

情境感知行銷的真正價值。不在於把客戶名字填進訊息開頭那種表面工夫。而在於讀懂使用者「此刻的狀態」。再依這個當下挑出最貼合的訊息。它需要三層資料當燃料、需要一條會自我校準的回饋迴路、更需要建立在正當使用資料的基礎上。與其追問「我們能不能做個人化」。不如問「我這個情境的訊號拿不拿得到、訊息備不備得齊、成效驗不驗證得了」。下一步建議你挑一個價值最高的單一情境場景當試點。盤點手上合法可用的資料。備好候選訊息與觸發規則。用對照組小範圍試跑並量出增益。確認有效之後再逐步擴大到其他情境。讓情境感知行銷在你的組織裡。從一個成功的場景慢慢長成一套成熟的能力。
