# 債務規劃與雪球還債法：還債計劃計算器使用指南與理財策略

## 一、前言與定義

在現代社會中，個人債務問題日益普遍，無論是信用卡卡債還是信用貸款，妥善的債務規劃都是實現財務自由的關鍵。還債計劃計算器是一款專為個人債務整理與理財規劃設計的實用工具。透過系統化的數據分析，它能幫助使用者清晰掌握負債狀況，並制定出最有效的還款策略。

其中，「雪球還債法」與「雪崩還債法」是兩種最常見的策略[1]。雪球還債法主張優先償還餘額最小的債務，藉由快速消除小額債務建立成就感；而雪崩還債法則建議優先償還利率最高的債務，以節省最多利息。無論選擇何種策略，本計算器都能提供精確的指引。

## 二、核心公式與運算邏輯

還債計劃計算器的核心在於計算每期還款後的剩餘本金與利息。其基本運算邏輯基於複利攤銷公式。

每月利息計算公式：
$I_t = B_{t-1} \times \frac{r}{12}$

每月剩餘本金計算公式：
$B_t = B_{t-1} + I_t - P_t$

以下為公式中各項變數的詳細說明：

| 變數符號 | 變數名稱 | 詳細說明 |
| :--- | :--- | :--- |
| $I_t$ | 當期利息 | 第 $t$ 期所產生的利息費用。 |
| $B_{t-1}$ | 前期剩餘本金 | 上一期期末尚未償還的債務本金總額。 |
| $r$ | 年利率 | 該筆債務的年度名目利率，需除以 12 轉換為月利率。 |
| $B_t$ | 當期剩餘本金 | 第 $t$ 期還款後的剩餘債務本金總額。 |
| $P_t$ | 當期還款金額 | 第 $t$ 期實際支付的還款總額，包含本金與利息。 |

## 三、真實案例與計算步驟

假設小明有兩筆債務需進行債務整理：
1. 信用卡：本金 50,000 元，年利率 15%，最低還款 3,000 元。
2. 信貸：本金 200,000 元，年利率 6%，最低還款 5,000 元。

小明每月有額外 2,000 元預算。若採用「雪球還債法」，步驟如下：
1. **排序**：優先處理餘額較小的信用卡債務。
2. **分配**：信貸繳交 5,000 元；信用卡繳交 5,000 元。
3. **計算首月**：信用卡利息為 $50,000 \times (15\% / 12) = 625$ 元。本金減少 $5,000 - 625 = 4,375$ 元。剩餘本金為 45,625 元。
4. **滾動**：信用卡還清後，將這 5,000 元滾入信貸還款，加速清償。

## 五、常見問題解答 (FAQ)

**Q1：什麼是雪球還債法？**
A1：這是一種優先償還餘額最小債務的策略。還清後將資金加到下一筆債務，能快速減少債務筆數，建立理財規劃的自信。

**Q2：雪球還債法與雪崩還債法有何不同？**
A2：雪球法著重心理激勵，優先處理小額債務；雪崩法則著重數學最佳化，優先償還高利率債務以節省利息。

**Q3：沒有額外資金還能使用計算器嗎？**
A3：可以。計算器能幫您統整個人債務，了解在僅繳最低還款額時所需的清償時間。

**Q4：債務整合會比雪球還債法更好嗎？**
A4：若能申請到低利率的整合貸款，可能更具優勢。但無論是否整合，制定並執行還款計畫都是必要的。

**Q5：應該多久更新一次數據？**
A5：建議每月繳納帳單後定期更新剩餘本金，以確保計畫準確並強化還債動力。
