# 租金殖利率計算器使用指南：掌握房地產投資的被動收入關鍵

## 一、前言與定義
在投資環境中，房地產始終是追求穩定被動收入的首選。對有志成為包租公的投資者而言，評估潛在回報是成敗關鍵。其中，「租金殖利率」（Rental Yield）是最核心的指標。
租金殖利率指年度租金收入佔房地產總投資成本的百分比。它能幫助投資者比較不同物件的效益，作為資金運用效率的依據。準確計算租金殖利率，可避免盲目追高房價，確保資金產生預期現金流。

## 二、核心公式與運算邏輯
租金殖利率分為「毛租金殖利率」與「淨租金殖利率」。為精確反映回報，專業投資者通常著重淨租金殖利率。
核心公式如下：
**淨租金殖利率 = [(每月租金收入 × 12) - 年度相關支出] / 房地產總投資成本 × 100%**

| 變數名稱 | 定義與說明 | 包含項目範例 |
| :--- | :--- | :--- |
| 每月租金收入 | 房客每月實際支付的租金。 | 房屋與車位租金。 |
| 年度相關支出 | 維持營運與出租的年度費用。 | 房屋稅、管理費、修繕費等。 |
| 房地產總投資成本 | 取得房地產投入的總資金。 | 房屋總價、仲介費、裝潢費等。 |

## 三、真實案例與計算步驟
假設小明購買套房出租，財務數據如下：
- 房屋總價：8,000,000 元
- 購屋相關費用：200,000 元
- 裝潢與家具：800,000 元
- 每月預期租金：25,000 元
- 年度相關支出：60,000 元

**計算步驟：**
1. **總投資成本**：8,000,000 + 200,000 + 800,000 = 9,000,000 元。
2. **年度總租金**：25,000 × 12 = 300,000 元。
3. **年度淨租金**：300,000 - 60,000 = 240,000 元。
4. **淨租金殖利率**：(240,000 / 9,000,000) × 100% = 2.67%。
小明可得知淨租金殖利率約 2.67%，並與定存利率比較，評估是否符合目標。

## 五、常見問題解答 (FAQ)
**Q1：租金殖利率多少才算合理？**
A1：因地區與物件而異。在台灣都會區，淨租金殖利率達 2.5% 至 3% 以上，通常具備基本投資價值。

**Q2：毛租金與淨租金殖利率有何不同？**
A2：毛租金殖利率未扣除持有成本；淨租金殖利率則扣除年度支出，並將裝潢計入總投資，更能反映實際收益。

**Q3：計算時需要考慮房屋貸款利息嗎？**
A3：標準計算不含貸款利息，以評估物件本身收益能力。若評估自有資金回報率，才需納入貸款本息。

**Q4：房屋有空置期該如何調整？**
A4：建議保守估計，將全年租金收入乘以 90% 或 95%，以獲得更穩健的財務預測。

**Q5：殖利率越高的物件投資價值越高嗎？**
A5：不一定。高殖利率可能伴隨高風險，如偏遠地區或需頻繁修繕。投資者須審慎評估流動性與管理成本。

## 六、結語與建議
租金殖利率是評估房地產投資不可或缺的羅盤。透過科學化計算，投資者能篩選出具備現金流的優質物件，建立被動收入系統。
建議有志成為包租公的投資者，購屋前詳實調查租金行情與隱藏成本，並善用本計算器進行模擬分析。建立在嚴謹數據上的決策，才能在房地產市場中持盈保泰。
