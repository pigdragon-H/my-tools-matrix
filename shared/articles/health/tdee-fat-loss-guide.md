# 減脂期間怎麼吃？TDEE 熱量缺口完整攻略，科學減脂不復胖

減肥失敗的人，大多敗在「以為少吃就好」。少吃確實是減脂的核心，但少多少？吃什麼？什麼時候吃？這些細節決定了你是「健康減脂」還是「越減越胖的溜溜球效應」。本文用 TDEE 科學框架，給你一套可以長期執行的減脂飲食攻略。

---

## 什麼是 TDEE？為什麼它是減脂的關鍵？

**TDEE（Total Daily Energy Expenditure）** 是你的每日總熱量消耗，包含：

- **BMR（基礎代謝率）**：維持生命基本運作的熱量（呼吸、心跳、體溫調節）
- **活動量消耗**：日常活動、工作、運動消耗的熱量
- **食物熱效應**：消化食物本身也需要消耗能量（約佔總攝取的 10%）

**減脂的核心原理：**

```
攝取熱量 < TDEE → 身體動用脂肪儲備 → 體重下降
```

聽起來很簡單，但魔鬼藏在細節裡。

---

## 計算你的 TDEE：活動係數很重要

TDEE = BMR × 活動係數

| 活動程度 | 描述 | 係數 |
|---|---|---|
| 久坐不動 | 辦公室工作，幾乎不運動 | × 1.2 |
| 輕度活動 | 每週運動 1～3 次 | × 1.375 |
| 中度活動 | 每週運動 3～5 次 | × 1.55 |
| 高度活動 | 每週運動 6～7 次 | × 1.725 |
| 非常高度 | 體力勞動工作 + 每日運動 | × 1.9 |

**台灣人最常犯的錯誤**：高估自己的活動量。「我每天走路上班」不等於「輕度活動」，很多人其實應該選「久坐不動」。高估活動量 → TDEE 算高 → 實際吃太多 → 瘦不了。

---

## 減脂期的熱量缺口設定

知道你的 TDEE 後，設定合理的熱量缺口：

| 缺口大小 | 每週預期減重 | 適合對象 |
|---|---|---|
| -250 大卡/日 | 約 0.25 公斤/週 | 初學者、輕度超重 |
| -500 大卡/日 | 約 0.5 公斤/週 | 大多數人的最佳選擇 |
| -750 大卡/日 | 約 0.75 公斤/週 | 有運動習慣者 |
| -1000 大卡/日 | 約 1 公斤/週 | 極限，不建議長期執行 |

**黃金法則：每日缺口不超過 500 大卡，每週減重不超過 0.5～1 公斤。**

超過這個速度，你失去的不只是脂肪，還有大量肌肉——肌肉流失 → 基礎代謝下降 → 越來越難瘦，這就是溜溜球效應的根源。

## 減脂期三大營養素怎麼分配？

確定熱量後，接下來是怎麼把這些熱量「填滿」：

### 蛋白質：減脂期的主角

**建議攝取量：體重（公斤）× 1.6～2.2 克**

例如：60 公斤的人，每天需要 96～132 克蛋白質

為什麼蛋白質這麼重要？
- 保留肌肉量（減脂最重要的目標之一）
- 飽足感最強，減少進食衝動
- 食物熱效應最高（消化蛋白質消耗的熱量最多）

**優質蛋白質來源：**
雞胸肉、鮪魚罐頭、豆腐、雞蛋、希臘優格、毛豆

### 碳水化合物：不是敵人，是燃料

**建議攝取量：剩餘熱量的 40～50%**

低碳飲食雖然短期有效，但長期不可持續，且影響運動表現。選**低 GI 碳水**（燕麥、糙米、地瓜、全麥麵包），讓血糖穩定，減少飢餓感。

### 脂肪：不能省，省了會後悔

**建議攝取量：剩餘熱量的 25～35%**

脂肪攝取過低 → 荷爾蒙分泌異常 → 影響代謝與睡眠品質。選擇**好脂肪**（橄欖油、堅果、酪梨、深海魚）。

## 減脂飲食常見誤區

**誤區一：不吃早餐可以少攝取熱量**
研究顯示，不吃早餐往往導致午餐和下午茶攝取更多熱量，整體熱量不減反增。

**誤區二：只喝代餐就好**
代餐可以短期使用，但缺乏天然食物的纖維素、植化素，長期不利腸道健康與飽足感。

**誤區三：有運動就可以多吃**
「跑了30分鐘消耗300大卡，所以可以多吃一塊蛋糕」——蛋糕大概是350大卡。運動消耗很容易被高估，食物熱量很容易被低估。
